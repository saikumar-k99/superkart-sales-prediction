# SuperKart - Sales Forecasting

A Flask REST API and a Streamlit UI that predict `Product_Store_Sales_Total` - the revenue generated by a product in a SuperKart store.

| Folder | Content | Port |
|--------|---------|------|
| `backend/` | Flask API (`/v1/predict`, `/v1/predictbatch`) served by Gunicorn, together with the serialized model | 7860 |
| `frontend/` | Streamlit app that calls the API | 8501 |

## Run both containers (GitHub Codespaces or any machine with Docker)

```bash
docker network create superkart-network

cd backend
docker build -t superkart-backend .
docker run -d --name backend --network superkart-network -p 7860:7860 superkart-backend

cd ../frontend
docker build -t superkart-frontend .
docker run -d --name frontend --network superkart-network -p 8501:8501 superkart-frontend
```

The Streamlit container reaches the API through the Docker network at `http://backend:7860`.

* Streamlit UI: port **8501**
* Flask API: port **7860** (make the port Public in the Codespaces *Ports* tab to call it from outside)

## Call the API

```bash
curl -X POST "<API_URL>/v1/predict" -H "Content-Type: application/json" -d '{
  "Product_Weight": 12.66, "Product_Sugar_Content": "Low Sugar", "Product_Allocated_Area": 0.027,
  "Product_MRP": 117.08, "Store_Size": "Medium", "Store_Location_City_Type": "Tier 2",
  "Store_Type": "Supermarket Type2", "Product_Id_char": "FD", "Store_Age_Years": 16,
  "Product_Type_Category": "Non Perishables"}'

curl -X POST "<API_URL>/v1/predictbatch" -F "file=@Batch_Data_SuperKart.csv"
```
